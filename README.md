# FoodWagon - Food Delivery Service Website

Welcome to FoodWagon, a modern and responsive landing page for a fictional food delivery service. This project showcases a clean user interface designed to attract customers, restaurant partners, and delivery drivers.

## ✨ Features

- **Fully Responsive Design:** Adapts seamlessly to all device sizes, from mobile phones to desktop monitors.
- **Engaging Hero Section:** A captivating video background with a clear call-to-action.
- **"How It Works" Section:** A clear, three-step guide to using the service.
- **Interactive Sections:** Clearly defined sections for customers, restaurant partners, and potential drivers.
- **Mobile-Friendly Navigation:** A hamburger menu for easy navigation on smaller screens.
- **Interactive AI Chatbot:** A floating chatbot icon that opens a message window and simulates a conversation.
- **Multiple Pages:** Includes separate, styled pages for Login/Signup and Subscriptions.
- **Clean Footer:** A well-organized footer with links to important pages.
- **Cross-Browser Compatibility:** Works on modern web browsers.
- **Accessibility & UX:** Includes ARIA labels for screen readers, visible focus states for keyboard navigation, and lazy loading for images.

## 🛠️ Technologies Used

- **HTML5:** For the structure and content of the website.
- **CSS3:** For styling, layout (Flexbox), responsiveness (Media Queries), and maintainability (CSS Custom Properties).
- **JavaScript (Vanilla):** For interactive elements like the mobile menu and the chatbot popup.
- **Font Awesome:** For icons used throughout the site.

## ⚙️ How To Use

To run this project locally, simply download the files and open the `index.html` file in your web browser.

```bash
# Clone the repository (optional)
git clone https://github.com/your-username/foodwagon.git

# Navigate to the project directory
cd foodwagon

# Open the main file
open index.html
```

## ⚡️ Performance & Optimization

For deployment, it is highly recommended to compress the project's assets to improve loading times.

-   **Images:** Compress all `.jpg` files using a service like [TinyPNG](https://tinypng.com/) or an application like [Squoosh](https://squoosh.app/).
-   **Video:** The `hero-video.mp4` file should be compressed using a tool like [HandBrake](https://handbrake.fr/) to reduce its file size.

The site already implements `loading="lazy"` on images below the fold to defer their loading until they are needed.
